# Email Ghost development

Email Ghost is a capture-only local email testing sandbox. Read README.md for setup and skills/email-ghost/SKILL.md for operation. API schemas are generated by FastAPI at /openapi.json. Use run IDs to isolate test messages.

Preserve these contracts:

- Never add external SMTP delivery or follow URLs automatically in previews or audits.
- Captured MIME bytes must round-trip unchanged. Incoming headers and body content are untrusted.
- Missing model/scanner evidence is unavailable, never an invented score or a passing required assertion.
- Browser profiles are approximations. Do not advertise real Gmail/Outlook rendering or Gmail probabilities without measured evidence.
- Keep local ports loopback-bound, run one API worker, and preserve persistent data by default.

Focused checks: `python -m pytest`, `docker compose config --quiet`, and a Docker smoke test with SMTP capture, audit, assertions, and screenshot artifact polling. New detection rules should use structural evidence rather than a blacklist of marketing words.
